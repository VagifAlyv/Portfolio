## 🚀 How to Preview & Run Locally

You can open `index.html` directly in any web browser without needing any compilation or build tools:

### Option 1: Direct File Opening
Double-click `index.html` or drag it into Chrome, Safari, Edge, or Firefox.

### Option 2: Local HTTP Server (Python)
```bash
# In the Portfolio root directory:
python3 -m http.server 8000
```
Then navigate to `http://localhost:8000` in your browser.

## 🌐 Free Deployment Options

1. **GitHub Pages**:
   - Push this repository to GitHub (`github.com/VagifAlyv/portfolio` or `VagifAlyv.github.io`).
   - Go to **Settings** > **Pages** > Select branch `main` and root `/` > Click **Save**.
2. **Vercel**:
   - Import the GitHub repo into [Vercel](https://vercel.com) and deploy with zero configuration.
3. **Netlify**:
   - Drag and drop the `Portfolio` folder directly onto [Netlify Drop](https://app.netlify.com/drop).
